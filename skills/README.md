### everything-find

使用 Everything 搜索来替代本地查找命令如 `where`，提高代理在全局或大路径范围内的搜索效率。

在使用此技能之前，请确保你的系统是 Windows。

```bash
npx skills@latest add tangsong404/tangs-toolbox/skills/everything-find
```

### silent-gui-test

让桌面 GUI 自动化测试只发生在虚拟屏幕里：不抢焦点、不动光标、不占用用户桌面，并以 `PrintWindow` 抓窗口截图。附带 `scripts/silent-probe.ps1` 通用探针脚本。

在使用此技能之前，请确保你的系统是 Windows。

```bash
npx skills@latest add tangsong404/tangs-toolbox/skills/silent-gui-test
```
