# ccursor-cli

[CometixSpace/CCursor: Bring Your Own Key for Cursor IDE！](https://github.com/CometixSpace/CCursor)

基于`Cursor++`打补丁，以三方运行模型运行 `Cursor CLI` 

## 快速开始

``````
npx @tangsong404/ccursor-cli
``````

## 开发

```cmd
git clone https://github.com/tangsong404/tangs-toolbox
cd ccursor-cli
npm run bootstrap
```
